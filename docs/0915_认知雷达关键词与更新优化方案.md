# 0915 认知雷达关键词与更新优化方案

日期：2026-09-15

本次为公司现有版本补充两类设计：领导可用的拆分关键词，以及根据对话与 Web Search 信源更新总体报告和子问题报告的方案。

详细内容保存在独立目录：[`0915_关键词与报告更新优化方案`](0915_关键词与报告更新优化方案/README.md)。

## 本次结论

- 区分给领导看的 2—6 字模块短标题和给 Web Search 使用的检索查询。
- 当前拆分只有一个 `query/topic`：先识别 Topic 类型；仅在原文明确表达时提取具体意图，否则采用综合认知模式，再根据材料议题生成完整子问题并压缩标题。
- 领导视角决定问题的管理意义和优先级，材料决定本次能形成哪些正式模块。
- 更新接口同时检查回答中的候选认识和本轮信源对旧观点的直接反证，结果可以是新增、修正、退出、保留冲突或不更新。
- 认知变更优先路由到最具体的子问题报告；只有改变总体结论、优先级、资源、风险、时点或观察信号时才联动总体报告。
- Query 参与范围解析、材料排序、覆盖检查和审计，但事实依据必须来自 Query 找到的文献原文。
- 总体和子问题报告同时变化时，以一个更新批次生成完整候选文件；确认后校验全部基线版本并一致提交。
